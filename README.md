# إنجزلي ENJEZLY

نظام أولي لإدارة مكتبات الطباعة والاستديوهات مبني باستخدام HTML وCSS وTypeScript وVite.

## التشغيل على Windows أو Ubuntu

1. ثبّت Node.js إصدار LTS من الموقع الرسمي: https://nodejs.org/
2. فك ضغط المشروع.
3. افتح مجلد `enjezly` في VS Code.
4. افتح Terminal داخل المجلد.
5. نفّذ:

```bash
npm install
npm run dev
```

6. افتح رابط localhost الذي يظهر في Terminal.

## إنشاء نسخة جاهزة للنشر

```bash
npm run build
```

سيتم إنشاء مجلد `dist`.

## المميزات الحالية

- لوحة تحكم وإحصائيات.
- إضافة الطلبات وتحديث حالتها وحذفها.
- البحث في الطلبات.
- تجميع العملاء تلقائياً من الطلبات.
- ملخص المبيعات والمدفوعات والمتبقي.
- تصدير الطلبات إلى CSV.
- حفظ الطلبات محلياً في المتصفح عبر localStorage.

## ملاحظات مهمة

هذه نسخة MVP تجريبية. البيانات محفوظة في المتصفح الحالي فقط وليست قاعدة بيانات مشتركة بين الأجهزة. تسجيل الدخول الحقيقي، قاعدة البيانات السحابية، إدارة مخزون قابلة للتعديل، رفع الملفات، صلاحيات الموظفين، والنسخ الاحتياطي تحتاج مرحلة ربط Backend وقاعدة بيانات.
