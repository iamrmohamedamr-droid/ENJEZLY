# إنجزلي ENJEZLY

نظام إدارة مكتبات الطباعة والاستديوهات باستخدام HTML وCSS وTypeScript وVite، مع مساعد ذكي عبر Groq.

## تشغيل المشروع محلياً

1. ثبّت Node.js LTS.
2. فك ضغط المشروع وافتح المجلد في VS Code.
3. افتح Terminal ونفّذ `npm install`.
4. انسخ `.env.example` إلى ملف جديد اسمه `.env`.
5. أنشئ API Key من لوحة Groq وضعه في `GROQ_API_KEY` داخل `.env` (لا ترسله لأحد ولا تضعه داخل ملفات الواجهة).
6. شغّل `npm run dev` وافتح رابط Vite الظاهر في Terminal.

## إنشاء نسخة النشر

نفّذ `npm run build` لإنشاء مجلد `dist`. يوجد مسار API متوافق مع Vercel في `api/chat.ts`. عند النشر على Vercel أضف متغيرات البيئة `GROQ_API_KEY` و`GROQ_MODEL` من إعدادات المشروع.

## المساعد الذكي

- محادثة عربية مع Groq Chat Completions API.
- يقرأ ملخص الطلبات والإجماليات الحالية التي يرسلها المتصفح.
- يستطيع تلخيص حالات الطلبات والمبيعات والمدفوعات والمتبقي، وتقديم اقتراحات تشغيلية.
- لا يعدّل أو يحذف الطلبات بنفسه في هذه النسخة.
- النموذج الافتراضي `openai/gpt-oss-20b` ويمكن تغييره من `GROQ_MODEL`.

## الخصوصية والأمان

مفتاح Groq محفوظ في متغير بيئة على الخادم ولا يُرسل إلى المتصفح. عند استخدام المساعد، يتم إرسال سجل المحادثة وملخص بيانات الطلبات (بما فيها أسماء العملاء وأرقام الطلبات ومواصفات الطلب والمبالغ، دون أرقام هواتف) إلى Groq لتوليد الرد. استخدم بيانات تجريبية أثناء الاختبار، وأضف تسجيل الدخول والصلاحيات وقاعدة بيانات مشتركة قبل تشغيل النظام ببيانات عملاء حقيقية.

## حدود النسخة الحالية

بيانات الطلبات ما زالت محفوظة في `localStorage` لكل متصفح، وليست قاعدة بيانات مشتركة بين الأجهزة. صفحة المساعد تقرأ بيانات المتصفح الحالي فقط. تسجيل دخول المدير، أدوار الموظفين، وربط المساعد بأوامر تنفيذ فعلية تتطلب Backend وقاعدة بيانات وصلاحيات آمنة في مرحلة لاحقة.
